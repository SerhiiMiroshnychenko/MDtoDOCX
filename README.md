# MDtoDOCX — Markdown to Word Converter

Client-side Markdown to `.docx` converter built with React + TypeScript + Vite.

## Features

- Convert Markdown to Word (.docx) entirely in the browser
- Live preview with multiple view modes
- Customizable themes, fonts, margins, orientation
- Title page, headers/footers, table of contents, page numbers
- Import `.md` files or use built-in templates
- Text modifiers: find/replace, case change, beautify, TOC generator
- Zero backend — fully static, ready for GitHub Pages

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
